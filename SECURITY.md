# Security Policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for a security
vulnerability. Instead, use GitHub's private vulnerability reporting:

**Repository → Security tab → "Report a vulnerability."**

If that's not available on this repository yet, open a regular issue
asking for a private contact channel to be set up, without describing
the vulnerability itself, and a maintainer will follow up.

Please include: what you found, the affected file(s)/command(s), and
steps to reproduce. We'll acknowledge reports as promptly as we can;
this is a small, actively-developed project without a formal SLA yet.

## Scope

In scope: the `brute` core engine crate, the `desktop/` Tauri
application, the release packaging scripts, and the CI workflows in
this repository.

Out of scope: third-party dependencies' own vulnerabilities (report
those upstream; `dependabot.yml` in this repo tracks dependency
updates), and the bundled llama.cpp binaries' own code (report those to
[ggml-org/llama.cpp](https://github.com/ggml-org/llama.cpp)).

## Supported versions

This project is in beta (pre-1.0). Security fixes land on the latest
released version; older beta releases are not separately patched.

## The network-path audit

Because "does this app phone home" is exactly the kind of question a
security-conscious reader wants answered without having to trust a
claim, here is the complete, exhaustive list of every network-capable
code path in this repository as of this writing:

| Location | What it does | Trigger |
|---|---|---|
| `desktop/src-tauri/src/commands/download.rs` (`ureq` crate) | Downloads a model file to disk | **Explicit user click** on a specific "download this model" button, after the destination/size/license are shown |
| `desktop/src-tauri/src/lib.rs` (`tauri-plugin-opener`) | Opens a URL in the user's default system browser (a separate OS process — never loads inside the BRUTE window) | **Explicit user click** on "Open official source," after a URL-safety check (`desktop/src/lib/urlSafety.ts`) rejects anything that isn't a well-formed public http(s) address |

That is the complete list. There is no other network-capable code
anywhere in this repository:

- The core `brute` engine crate (root `Cargo.toml`) has **zero**
  HTTP/TLS/socket dependencies — there is nothing to audit at runtime
  because nothing in that crate can open a network connection at all.
  `ureq` is a dependency of `desktop/src-tauri` only.
- No telemetry, analytics, crash-reporting, or remote-logging SDK is a
  dependency anywhere in this repository (frontend `package.json`,
  root `Cargo.toml`, or `desktop/src-tauri/Cargo.toml`).
- No Tauri plugin with network capability (updater, HTTP client, etc.)
  beyond the two rows above.
- A Rust-level WebView navigation guard
  (`desktop/src-tauri/src/lib.rs`'s `navigation_guard`) additionally
  rejects any attempt to navigate the app's main window away from its
  own bundled pages, regardless of cause.

This table is regenerated by re-auditing the source, not copy-pasted
year over year — if you find a network call this table doesn't
mention, that's a bug (and likely a security issue) — please report it.

See [`docs/security-model.md`](docs/security-model.md) for the deeper
threat model (binary verification, supply-chain trust, path-traversal
guards, process-launch safety) and [`PRIVACY.md`](PRIVACY.md) for the
privacy-focused summary of the same facts.

## Known security-relevant limitations

- **This beta is unsigned.** No code-signing certificate was available
  for this release; Windows SmartScreen will show an "Unknown
  Publisher" warning. This is disclosed, not hidden — see
  [`docs/windows-packaging.md`](docs/windows-packaging.md).
- See [`docs/known-limitations.md`](docs/known-limitations.md) for the
  complete, honest list of gaps found during development and
  verification.
