# Contributing

Thanks for your interest in BRUTE Runtime.

## Current contribution status

**This repository's source-code license has not been finalized yet**
(see [`LICENSE-NOTICE.md`](LICENSE-NOTICE.md)). Until that's resolved,
we can't accept code contributions (pull requests) in good faith — we'd
have no clear terms to tell you your contribution would be released
under. This is a deliberate, temporary state, not a "closed project"
stance.

**What's welcome right now:**

- Bug reports (use the issue templates under **Issues → New Issue**).
- Feature suggestions and discussion.
- Documentation corrections/clarity feedback (open an issue describing
  the problem — please hold off on a PR until licensing is resolved).
- Security reports — see [`SECURITY.md`](SECURITY.md), please report
  privately rather than as a public issue.

**Once a license is chosen**, this document will be updated with a real
contribution workflow (branch conventions, PR review process, DCO/CLA
if applicable). Watch [`README.md`](README.md#license-status) for that
update.

## Reporting a good bug

Please include:

- What you did, what you expected, what actually happened.
- Windows version and whether you're on the installed app or building
  from source.
- Whether the issue reproduces in a fresh install (helps rule out local
  state issues — see [`PRIVACY.md`](PRIVACY.md) for where local state
  lives if you want to reset it yourself first).
- Relevant output — but please **do not** paste full hardware reports
  or exported library files without checking them for anything you
  don't want to share; BRUTE's own export functions redact known
  machine identifiers, but always double-check before pasting.
