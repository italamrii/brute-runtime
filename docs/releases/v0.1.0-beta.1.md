# BRUTE Runtime v0.1.0-beta.1 — Windows Beta

By Engineer Abdullah Alamri · بواسطة المهندس عبدالله العمري

**بياناتك ما تطلع من جهازك — your data never leaves your device.**

This is the first public beta of BRUTE Runtime: a local-first Windows
desktop app for running open GGUF models on your own hardware, with
hardware-aware recommendations, automatic tuning, and a trusted local
model library — no cloud, no account, no telemetry.

## What's in this release

- **Local AI execution.** Run GGUF models entirely on your device via a
  bundled CPU llama.cpp runtime — no separate download or setup needed
  to get started.
- **Real hardware detection.** CPU, RAM, GPU (name/VRAM via DXGI, NVIDIA
  driver via `nvidia-smi`), CUDA/Vulkan presence, storage, and power
  state — every field labeled measured/detected/inferred/unavailable,
  never a guessed default.
- **GGUF model discovery.** Automatically scans a fixed, safe set of
  common folders (Downloads, Documents, `C:\Models`, LM Studio's and
  Ollama's caches) for models you already have — never a whole-disk
  scan, never automatic/background.
- **Hardware-aware recommendations.** The Discover Models catalog ranks
  curated model builds against your actual measured hardware and
  explains why, with an honest six-state fit classification (`Unknown`
  is never collapsed into "not recommended").
- **Automatic tuning.** Benchmarks a small, bounded set of runtime
  configurations (threads, GPU offload, context/batch) safely and saves
  the most stable, best-performing one as a reusable local profile.
- **Arabic and English UI.** Full RTL/LTR layout switching, not a
  partial translation.
- **No accounts, no telemetry.** See [Privacy and network paths](#privacy-and-network-paths).

## Installed Windows verification

Verified on real hardware, in the actual installed NSIS build (not just
`tauri dev`):

- Clean install → Start Menu/taskbar icon shows the official BRUTE
  branding → app launches with the correct window title.
- Runtime auto-resolves to the bundled CPU llama.cpp runtime with no
  manual configuration.
- Hardware detection and model discovery run without freezing the UI.
- A real local generation was run end-to-end (Qwen2.5-0.5B-Instruct,
  Q4_K_M) with streamed output and measured throughput.
- No visible console window flash during hardware detection or model
  execution — confirmed via parent-process-scoped Win32 window
  monitoring, not just a visual glance.
- Clean process shutdown: no orphaned `llama-cli.exe` or WebView2
  process after Stop or app close.
- Clean uninstall: the app and its Start Menu entry are removed;
  imported GGUF model files and `%LOCALAPPDATA%\BruteRuntime\` are left
  untouched, as documented.

See [`docs/stage-4-verification.md`](../stage-4-verification.md) and
[`docs/known-limitations.md`](../known-limitations.md) for the full
verification history, including two real bugs this process caught and
fixed (a Discover Models crash from a frontend/backend type mismatch,
and the console-window-flash issue above).

## Known limitations

Full, itemized list: [`docs/known-limitations.md`](../known-limitations.md).
Headline items for this release:

- **This beta is unsigned.** No commercial code-signing certificate was
  available. Windows SmartScreen will show an "Unknown Publisher"
  warning on first run — this is disclosed, not hidden.
- **Not every model runs on every device.** Recommendations are ranked
  against your real measured hardware and are explicit when a model is
  "Heavy" or "Not recommended" for your machine. BRUTE does not claim a
  model will run well on hardware it wasn't evaluated against.
- **macOS and Linux are compile-verified only.** The core engine builds
  cleanly for `x86_64-apple-darwin`, `aarch64-apple-darwin`, and
  `x86_64-unknown-linux-gnu`, but no macOS or Linux machine has executed
  this code — neither platform is release-ready. See
  [`docs/cross-platform.md`](../cross-platform.md).
- **No download pause/resume.** A cancelled model download restarts
  from zero (no HTTP range-request resumption yet).
- The catalog's `official_source_url` is a model's official page for
  license/provenance review, not a guaranteed direct file link — the
  in-app "Open official source" action always opens your system browser,
  never downloads automatically.

## Privacy and network paths

The **only** two network-capable code paths in the entire application:

1. An explicit, user-triggered model download (destination, size, and
   license shown before anything happens).
2. Opening a model's official source page in your system's default
   browser (a separate process — never inside the BRUTE window),
   triggered only by an explicit click, after a URL-safety check
   rejects localhost/loopback/private/malformed addresses.

No telemetry, analytics, crash reporting, remote logging, or background
network activity exists anywhere in this codebase. See
[`PRIVACY.md`](../../PRIVACY.md) and [`SECURITY.md`](../../SECURITY.md)
for the full audit.
