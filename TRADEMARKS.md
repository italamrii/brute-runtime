# Trademarks

"BRUTE", "BRUTE Runtime", the BRUTE wordmark, the BRUTE symbol/app icon
(the metallic "B" mark with the red accent), and the associated visual
identity (color palette, logo lockups, and tagline "POWER. CONTROL.
PERFORMANCE.") are the branding of the BRUTE Runtime project and its
creator, and are **not** covered by the source-availability terms in
[`LICENSE-NOTICE.md`](LICENSE-NOTICE.md) or any future open-source
license applied to the source code.

## What this means

Even after (or if) the source code is released under an open-source
license, that license governs the **code**, not the **brand**. This is
the same split many open-source projects use (source freely licensed,
name/logo separately protected) so that forks and redistributions
can't present themselves as the official project.

## Not permitted without explicit written permission

- Using the BRUTE name, logo, or icon to identify a modified, forked,
  or redistributed build in a way that could be mistaken for the
  official release.
- Using the BRUTE name or logo in a way that implies endorsement,
  sponsorship, or affiliation that doesn't exist.
- Using the logo/icon as the primary branding of another product or
  service.

## Generally fine (but ask if unsure)

- Referring to the project by name in your own writing, articles,
  comparisons, or discussion ("built with BRUTE Runtime's engine,"
  "a fork of BRUTE Runtime").
- Linking to this repository or its official release page.
- Screenshots of the actual, unmodified application for review,
  documentation, or educational purposes.
